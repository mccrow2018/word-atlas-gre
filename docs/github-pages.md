# GitHub Pages 部署与 iPhone 使用

本分支在原项目 Word Atlas 的基础上加入了两份 GRE 词库、固定五天等价词计划及每日 200 词的机经对齐顺序。保留原项目 MIT 代码许可和素材署名；GRE 资料授权另见 `CONTENT_LICENSE.md`。

## 自动发布

仓库的 Settings → Pages 中将 Source 设置为 GitHub Actions。推送 `main` 后，`.github/workflows/pages.yml` 自动安装依赖、验证词库、运行测试并发布。

工作流使用 `actions/configure-pages` 返回的 `base_path` 构建，所以部署在仓库子路径时，脚本、图片、录音、词库与离线缓存均使用正确路径。无需把 `dist/`、`node_modules/`、`tmp/`、原 PDF 或学习备份提交到 GitHub。

默认网站地址格式为 `https://<账号>.github.io/<仓库>/`。上线状态以 Actions 中最新一次 Pages 发布成功和网站实际可访问为准。

## iPhone 添加到主屏幕

1. 使用 Safari 打开发布后的 HTTPS 网址。
2. 点击分享按钮 → 添加到主屏幕；如有「作为 Web App 打开」选项，可开启。
3. 从主屏幕的「GRE 词光」图标打开。

生产版本启用 Service Worker，访问过的应用资源和词库会缓存；音频和图片按访问缓存，并非一次下载全部内容。设备语音的离线可用性取决于系统已安装的英语语音。

## 从本机迁移学习记录

新网址与 `localhost` 属于不同来源，浏览器不会自动转移本机进度。上线不会删除本机记录。

1. 在原本机页面选择一个词库，进入「我的」→ 导出备份。
2. 在新网址选择同一个词库，进入「我的」→ 导入备份。
3. 对另一份词库重复上述操作。

备份属于个人学习记录，请勿上传到公开仓库。

## 同步状态

GitHub Pages 只发布网站，目前进度仍保存在每台设备的浏览器。手机和电脑之间尚未自动同步；账号、云端数据库、离线补传和冲突合并需要另外实现。当前可用备份导入导出手工迁移。
